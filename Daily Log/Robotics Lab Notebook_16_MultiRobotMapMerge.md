# Chapter 1. Multi-Robot Map Merge

## Goal | 목표

3대의 TurtleBot3가 각각 생성한 OccupancyGrid map을 공통 좌표계인 `world`를 기준으로 정렬하고 하나의 `/merged_map`으로 통합하는 것을 목표로 하였다.

The objective was to merge the individual maps generated by three TurtleBot3 robots into a single global map using `world` as the common coordinate frame.

---

## Robot Configuration

3대의 로봇을 다음 위치에 배치하였다.

```text
tb3_0 = (-2.0, -2.0)
tb3_1 = (-2.0,  0.0)
tb3_2 = (-2.0,  2.0)
```

각 로봇은 독립적으로 SLAM Toolbox를 실행하여 다음 map을 생성하였다.

```text
/tb3_0/map
/tb3_1/map
/tb3_2/map
```

---

## Lab Summary

* 3대 TurtleBot3의 개별 SLAM map 생성
* House World 환경에서 Multi-Robot SLAM 구성

# Chapter 2. TF Structure

## Problem

초기에는 `world → tb3_X/odom` static TF를 사용하였다.

그러나 SLAM Toolbox가 이미

```text
tb3_X/map → tb3_X/odom
```

TF를 생성하고 있어 `odom` frame에 두 개의 parent가 발생하는 문제가 있었다.

---

## Solution

Static TF를 다음과 같이 수정하였다.

```text
world
 ├── tb3_0/map
 │      └── tb3_0/odom
 ├── tb3_1/map
 │      └── tb3_1/odom
 └── tb3_2/map
        └── tb3_2/odom
```

`world → tb3_X/map` 변환을 확인하여 각 map이 `world` 기준으로 배치되는 것을 확인하였다.

---

## Lab Summary

* 잘못된 `world → odom` 구조 수정
* `world → map → odom` TF 구조 구축
* TF 기반 map 정렬 환경 구성

# Chapter 3. Map Merge Node Implementation

## Goal | 목표

각 로봇의 OccupancyGrid를 수신하고 `world` 좌표계로 변환하여 `/merged_map`으로 publish하는 Map Merge Node를 구현하였다.

---

## Implementation

각 map을 subscription하였다.

```text
/tb3_0/map
/tb3_1/map
/tb3_2/map
```

TF2를 이용하여 각 로봇의 map frame을 `world` 기준으로 변환하였다.

```python
transform = self.tf_buffer.lookup_transform(
    "world",
    f"{robot_name}/map",
    rclpy.time.Time()
)
```

최종 map은:

```text
/merged_map
```

으로 publish하였다.

---

## Lab Summary

* 3개 OccupancyGrid subscription
* TF2 기반 좌표 변환
* `/merged_map` publisher 구현

# Chapter 4. OccupancyGrid Coordinate Transformation

## Investigation

각 로봇의 map 정보를 확인하였다.

```text
tb3_0: 119 × 70
tb3_1: 125 × 62
tb3_2: 114 × 107

resolution = 0.05 m
```

세 map의 resolution은 동일하지만 origin과 map 크기는 서로 달랐다.

---

## Implementation

각 cell을 map 좌표로 변환한 후 `world` 좌표로 변환하였다.

```text
OccupancyGrid Cell
        ↓
Map Origin
        ↓
tb3_X/map
        ↓
world
```

Global Bounding Box는 각 map의 네 모서리를 `world` 좌표로 변환하여 계산하였다.

---

## Lab Summary

* Map origin 및 resolution 반영
* Local Map → World 좌표 변환
* Global Bounding Box 계산

# Chapter 5. Map Merge Debugging & Result

## Problem

구현 과정에서 다음 오류가 발생하였다.

```text
AttributeError:
'MapMergeNode' object has no attribute 'map0_callback'
```

```text
IndexError:
index 126 is out of bounds
```

```text
UnboundLocalError:
local variable 'resolution' referenced before assignment
```

각 callback 정의, Global Map bounds check, 변수 초기화 순서를 수정하여 해결하였다.

또한 Local Map merge 과정에서 각 로봇의 `origin_x`, `origin_y`가 올바르게 적용되지 않는 문제를 발견하여 수정하였다.

---

## Result

최종 `/merged_map`을 확인하였다.

```text
frame_id  : world
resolution: 0.05 m
width     : 126 cells
height    : 260 cells
origin    : (-7.10, -5.72)
```

RViz에서 각 로봇의 SLAM map이 `world` 좌표계 기준으로 하나의 Global OccupancyGrid에 통합되는 것을 확인하였다.
